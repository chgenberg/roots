AGENT 01 — UX, FLÖDE, INFORMATION ARCHITECTURE, SAMTYCKE
=========================================================

MÅL
---
Designa världens mest tydliga, lugna och konverterande håranalys-online som leadmagnet:
användaren förstår vad som händer med bilder och data innan de laddar upp något.

PRINCIPER
---------
1. Progressiv avslöjning: kort intro → samtycke → foto-instruktioner → uppladdning → frågor → resultat.
2. Max 5–7 synliga steg i wizard; undvik scroll-maraton i ett enda steg.
3. Alltid möjlighet att gå tillbaka utan att förlora svar (client state).
4. Tydlig primär CTA på hero: t.ex. "Starta din håranalys" som öppnar modal.

STEG (REKOMMENDERAD ORDNING)
----------------------------
A. Intro: vad användaren får (hårbedömning + livsstils-/kosttips på allmän nivå + produktmatchning).
B. Samtycke: behandling av personuppgifter, fotons användning för analys, åldersgräns.
C. Foto bakifrån: instruktion (ljus, avstånd, torrt/tvättat enligt policy).
D. Foto uppifrån: samma.
E. Kort frågeformulär: t.ex. hur ofta tvätt, värmeverktyg, klor/saltvatten, stress/sömn, kostmönster (allmänt).
F. Analys: laddningsläge, ev. delresultat.
G. Resultat: sammanfattning + rekommendationer + diskret CTA (produktpaket / boka samtal).

LEADMAGNET
----------
- E-post kan vara valfri före resultat eller obligatorisk före "skicka analys" — välj en modell och var konsekvent.
- Rekommenderat: e-post + checkbox för nyhetsbrev (separat samtycke).

AVBROTT
-------
- Om användaren stänger modal: spara utkast i sessionStorage (valfritt) med TTL.

MÄTPUNKTER (PRODUKT)
--------------------
- Start wizard, complete wizard, consent rate, upload success rate, API error rate.
