GLOBALA PREMISSER (alla agenter)
--------------------------------
- Tre produkter: schampo, balsam, body wash
- Nordisk, minimalistisk, "cleant möbelföretag"-känsla
- Företagsberättelse: tre grundare över 1,95 m, olika bakgrund, gemensamt mål att stärka
  svenskt föreningsliv
- Få menyval, men kraftfull backend; ren frontend
- Vit bakgrund, mörkbrun signaturfärg
- Ingen emoji-estetik; professionell UI med subtil motion (pulserande accenter, flytande
  dekorativa element — sparsamt)
- Placeholders: Unsplash (fotorealistiskt, nordiskt ljus)
- Två inloggningsspår: klubbar (beställning) och säljare (order + offerter)
- Fortnox-koppling förberedd från början
- Open Claw integrerat från start (AI-/agentperspektiv)
