SCOUT 2 — Marketing pages
================================================================
Date: 2026-05-25 22:17
Scope: apps/web/src/app/(marketing)/{om-oss,kontakt,foreningsliv}/ + press/jobb anchors on om-oss

SUMMARY
-------
Marketing pages are structurally sound: real Swedish copy (no Lorem Ipsum), shared layout chrome, working internal routes, and a functional contact form with CSRF + rate limiting. The main MVP risk is narrative drift — especially on `/foreningsliv`, which still describes bulk portal ordering while the live product is seller-led fundraising campaigns — plus thin press/jobb sections and incomplete per-page SEO. Legal identity on `/kontakt` and footer is now solid (post prior audits).
Findings: 18 (P1:2 P2:6 P3:6 P4:4)
MVP readiness: 72/100

P1 — CRITICAL

[1.1] Föreningsliv page describes wrong business model for ASSOCIATION_ADMIN
  File: apps/web/src/app/(marketing)/foreningsliv/page.tsx:16-20,42-45,17-27
  Symptom: Steps promise “Beställ → Välj antal paket direkt i vår portal” and features promise “Administrera beställningar” / “Intäktsrapport”. Actual post-signup flow is register → create campaign → invite teams/sellers → supporters buy via personal shops (`/forening`, `/min-shop`).
  Root cause: Marketing copy written for a B2B wholesale ordering mental model; platform evolved to B2B2C fundraising without page rewrite.
  Fix: Rewrite STEPS/FEATURES/hero to match campaign → lag → säljare → delningslänk flow; mention margin/goal tracking in seller terms; link to `/registrera` with “förening” path called out explicitly.
  Effort: M

[1.2] Föreningsliv CTA lands on broken team-registration path
  File: apps/web/src/app/(marketing)/foreningsliv/page.tsx:48-52,145-148
  Symptom: Primary CTA “Anslut din förening” / “Registrera din förening” → `/registrera`. Team-leader path on that page calls `GET /v1/auth/organizations/search` anonymously and receives 401; UI shows empty org list with no error (`registrera/page.tsx:71-86`).
  Root cause: Org search requires session (`apps/api/src/routes/auth.ts:831-835`); marketing page gives no role split or warning.
  Fix: On `/foreningsliv`, clarify two paths (förening vs lagledare); open org search pre-auth or defer team search until after login; surface 401 copy on registrera.
  Effort: M
