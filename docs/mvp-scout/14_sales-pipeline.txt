SUMMARY
-------
Since the April 2026 sales-rep audit, Sprint C/E12 fixed the worst contract breaks: pipeline API now returns `stages` + `deals[]`, quote list/create use `salesRepId` correctly, portal offerter persist via `POST /v1/portal/quotes`, and hardcoded pipeline totals are gone. P1 — CRITICAL (blocks MVP for sales reps)

[1.1] No quote status lifecycle after create — reps cannot advance or close deals
  File: apps/api/src/routes/portal.ts (POST /quotes only; no PATCH)
        apps/web/src/app/(portal)/portal/offerter/page.tsx (read-only table)
  Symptom: Rep can create DRAFT or SENT at submit time only. Cannot later send a draft, mark accepted/rejected, or expire. Pipeline kanban is read-only; no UI action on quote rows.
  Root cause: No `PATCH /v1/portal/quotes/:id` (or equivalent) and no row actions in offerter table.
  Fix: Add PATCH with role + ownership guard; wire row actions (Skicka, Acceptera, Neka); on ACCEPTED optionally set org `crmStatus=CUSTOMER`.
  Effort: M
  Ref audit: [1.4]/[2.2] — partially fixed (create only)

[1.2] "Skicka offert" / status SENT does not deliver email or PDF
  File: apps/api/src/routes/portal.ts:1019–1106 (POST sets status, no mailer)
        apps/web/src/app/(portal)/portal/offerter/page.tsx:324–350
  Symptom: Checkbox "Skicka direkt" persists `status: SENT` in DB but customer receives nothing; rep believes quote was sent.
  Root cause: Send path never calls email template or attachment pipeline.
  Fix: On SENT transition, enqueue transactional email with quote summary/PDF link; surface send failure in UI.
  Effort: M–L
  Ref audit: [1.4] — STILL UNRESOLVED for actual delivery

[1.3] Sales dashboard pipeline funnel + top clubs never populate
  File: apps/web/src/app/(portal)/portal/page.tsx:54–59,212–231,270–323
        apps/api/src/routes/portal.ts:165–177 (dashboard stats omit `pipeline`, `topClubs`)
  Symptom: After successful `/dashboard` fetch, KPI cards show live numbers but the four-step funnel stays at 0/Lead–Stängd and "Toppklubbar" stays empty dashed box — even when `/portal/pipeline` has deals.
  Root cause: UI expects `stats.pipeline[]` and `stats.topClubs[]`; API never returns them (only scalar KPIs).
  Fix: Extend dashboard response with stage counts from `/pipeline` aggregates + top N orgs by revenue/quote value; or remove funnel until wired.
  Effort: S–M
  Ref audit: [2.3] KPI keys fixed; funnel data still missing

[1.4] Dashboard "Offerter ute" and "Stängda denna månad" use wrong counts
  File: apps/api/src/routes/portal.ts:131–144,158–171
        apps/web/src/app/(portal)/portal/page.tsx:225–226
  Symptom: "Offerter ute" counts **all** quotes for rep (includes ACCEPTED/REJECTED). "Stängda denna månad" counts **all-time** ACCEPTED with no month filter despite label.
  Root cause: `quoteCount` has no `status IN ('DRAFT','SENT')`; `closedCount` has no `created_at`/`updated_at` month window.
  Fix: Filter open quotes to non-terminal statuses; add `date_trunc('month', …)` filter for closed metric or rename label.
  Effort: S
  Ref audit: [2.4] — STILL UNRESOLVED
