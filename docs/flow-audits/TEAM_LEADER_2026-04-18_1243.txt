COACH-ON-SIDELINE QUICK WINS
----------------------------
1. **Fix long invite-URL rows on phone** — add `min-w-0` / `flex-1` + truncation (or stack) on `/lag` and `/lag/saljare` copy blocks to stop horizontal scroll/clipping at ~375px.
2. **Relabel or fix the “Beställningar” KPI** — it uses all order rows; “Total försäljning” is PAID-only; coaches misread momentum. Either filter the count to PAID or split “Väntande + betalda” vs “Intäkt (betalt)”.
3. **Show campaign `endDate` and “dagar kvar”** on team overview — field exists in DB; no code change to data model, only UI.
4. **Expose invite SMS/email text** — `getInviteTemplate` + `GET /v1/sharing/invite-template/:teamId` already return `sms`/`email`; web only copies raw URL. Add “Kopiera SMS” / show template.
5. **Surface `regenerateInviteToken` in UI** — server can rotate `teams.inviteToken`; team leaders have no “Ny länk” control for lost/stale links.
