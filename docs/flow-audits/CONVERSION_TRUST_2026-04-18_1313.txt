DARK PATTERNS / ETHICAL RED FLAGS (AUTO-P1)
---------------------------------------------
• **Unsourced “platform” statistics** on marketing (`500+`, `23` föreningar, `100%` ingredienser, milestone “12 / 5 / 3 föreningar”) — static arrays, **no “as of” date or data source** → **false bandwagon / social proof** if literals are not continuously true (`social-proof.tsx`, `gamification.tsx`, `haranalys/page.tsx`).
• **Portal “operations” UX** mixing **demo fallback** with partial API data — named clubs, amounts, timestamps can read as **real customer activity** (`portal/page.tsx`, `offerter/page.tsx`, `statistik/page.tsx`, `saljare/page.tsx`).
• **Inactive campaign still browsable/purchasable until checkout** — supporter invests time/cart before **“Kampanjen är inte aktiv”** (`checkout.ts` vs `shop/[slug]/page.tsx`).
• **Static “Komplett paket — 399 kr” / “Spara…”** block — **deal framing** not proven wired to bundle pricing/API (`shop/[slug]/page.tsx`).
• **Named seller leaderboards with SEK + medals + full rank** for fundraising teams — **high-pressure comparative ranking** with **no opt-out / age consent** (`lag/page.tsx`, `lag/saljare/page.tsx`).
• **Milestone labels say “paket”** while progress uses **`COUNT(*)` orders** — **misleading / rigged-feeling** progress (`milestones.ts`, `dashboard.ts`).
• **Portal AI marketing copy** promises pipeline/admin insights while API is **`public-chat`** — **narrative bait-and-switch** (`portal/ai/page.tsx` + `public-chat.ts`; aligns with AI audit).

TRUST GAPS — TOP 5
-------------------
1. **Legal entity footprint thin** — footer / kontakt / villkor / integritet often show **company name + Stockholm** but **no organisationsnummer, VAT, or street address** (`footer.tsx`, `kontakt/page.tsx`, `villkor/page.tsx`, `integritet/page.tsx`).
2. **`OrganizationJsonLd`** — **no `legalName`, address, `vatID`, rich `sameAs`** → weaker **structured trust** in discovery (`json-ld.tsx`).
3. **Transactional identity split** — emails/footer link **`rootshaircare.se`** and sender **`noreply@rootshaircare.se`** while web canonical is **`roots.se`** → **“same company?”** friction (`email/templates.ts`, `email/index.ts`, `layout.tsx`).
4. **Support channel fragmentation** — **`support@roots.se`** vs **`hej@roots.se`** across AI, hair analysis, public chat, legal pages (`system-prompt.ts`, `ai-chat.ts`, `hair-analysis.ts`, `public-chat.ts`, `kontakt`).
5. **Press / third-party proof thin** — **no awards strip**, press is **email-only**, **no named founders/team** with photos vs lifestyle/product imagery (`om-oss/page.tsx`, `founders.tsx`).

RETENTION LEAKS — TOP 5
------------------------
1. **No lifecycle job runner** — `pg-boss` in package.json **unused**; **no cron/worker** path for Day 3/7 winback (`package.json` pattern; Agent 6).
2. **`/registrera` abandonment** — **client `useState` only**, no partial save or resume email (`registrera/page.tsx`).
3. **`milestoneEmail`, `getMilestoneTemplate`, `getCampaignStartTemplate`** — **defined but never sent** / not wired to outbound mail (`email/templates.ts`, `communication-templates.ts`, routes grep).
4. **No dormant segmentation** — org schema lacks **`lastCampaignAt` / engagement flags** for winback queries (`organizations.ts` pattern).
5. **Password reset path** — **tRPC claims success** without verified send implementation (`trpc/routers/auth.ts`); trust + return gap for stuck users.
