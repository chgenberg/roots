REORDER FRICTION TOP ISSUES
----------------------------
1. **Dedicated `(club)` shell is largely non-functional for real commerce** — `trpc.club.orders` returns `[]`, `createOrder`/`dashboard` stubbed; `/club/bestall` uses `setTimeout`; `/club/historik` uses empty `DEMO_ORDERS` — no durable path for “buy again.”
2. **Portal catalog disconnect** — `/portal/produkter` keeps local quantities but navigating to `/portal/bestallningar` drops cart state (no shared cart / URL / POST bridge) — kills multi-line B2B ordering flow.
3. **No true one-click reorder, favorites, subscriptions, or “due reorder” reminders** anywhere in reviewed surfaces.
4. **`GET /v1/portal/orders` capped at `.limit(100)`** with no pagination/cursor — clubs with long history lack visibility beyond the cap.
5. **Two parallel club experiences** (`/club/*` demo shell vs `/portal/*` REST-backed flows) — risk wrong expectations, duplicated nav concepts (“Historik” vs “Beställningar”), and fragmented support/AI (`ChatWidget` only on `(club)`, not portal).
