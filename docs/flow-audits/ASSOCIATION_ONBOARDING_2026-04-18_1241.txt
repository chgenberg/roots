TOP DROPOFF RISKS
-----------------
1. **Lag/team registration org search is unusable pre-login:** `GET /organizations/search` returns 401 without a session; `/registrera` calls it anonymously → empty results with no error explanation — users believe the org “does not exist.”
2. **Campaign creation is not in the web app:** No campaign wizard under `/forening`; TRPC client unused in `apps/web`; association registration does not insert a campaign; team-leader registration only creates a team when an **active campaign** exists — otherwise onboarding stalls unless campaigns are created out-of-band.
3. **Post-login desert:** `/forening` has no first-run checklist, step progress, or “what first?” guidance; empty states (no campaign, no teams) often lack primary CTAs/deep links to the next action.
4. **Org profile & payouts gap:** `ASSOCIATION_ADMIN` nav has no org settings; `/club/konto` org save is a stub (TODO, fake success); no bankgiro/plusgiro in schema; orgnr not validated server-side — trust and operational completeness suffer after signup.
5. **Seller invite links are stable, multi-use, no TTL:** No expiry/single-use in DB or UI copy; security-conscious admins may hesitate; no rotate/resurface in web UI despite server-side token regeneration existing elsewhere.
